### Virtual Machine
- Windows or Linux OS
- Remote Desktop(RDP) or SSH를 통해 원격 연결이 가능
- 진짜 서버처럼 보이지만 가상 머신이다.
- 가상 머신은 가상 네트워크 안에 있어야 하며, 특정 타입의 가용성 집합으로 배열하거나 로드 밸런서 뒤에 배치할 수 있다.
